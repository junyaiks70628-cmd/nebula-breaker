NEBULA BREAKER PWA package

このZIPはホーム画面追加・オフラインキャッシュ対応版です。ただし、ZIPをFilesプレビューで開いても動作しません。

セットアップ:
1. このフォルダ内の4ファイルを、HTTPS対応の静的ホスティングにアップロードしてください（例: GitHub Pages / Netlify）。
2. iPhoneのSafariで公開URLをオンラインで一度開き、ゲームが起動することを確認します。数秒待ってキャッシュが完了するまでページを開いたままにします。
3. Safariの共有ボタン →「ホーム画面に追加」→「Webアプリとして開く」をオン →「追加」。
4. ホーム画面のNEBULAアイコンから起動し、動作確認後に機内モードで再度起動します。

重要:
- Service WorkerによるオフラインキャッシュはHTTPSなどの安全なオリジン上で動作します。ローカルZIPだけでは登録できません。
- ゲームプレイ中に外部通信は使用しません。
- このZIP自体はiOSネイティブアプリ/IPAではありません。App StoreアプリにするにはMacのXcode等でのビルドが必要です。
